# CCNA Networking Labs

A practical networking portfolio documenting my CCNA-level hands-on experience with Cisco routers, switches, GNS3, and Cisco Packet Tracer.

## What You'll Find

- Network Fundamentals
- IP Addressing & Subnetting
- VLANs & Trunking
- Inter-VLAN Routing
- STP & VTP
- Static & Dynamic Routing
- OSPF
- DHCP, NAT & PAT
- ACLs & Basic Network Security
- Network Troubleshooting
- Master CCNA Integrated Lab

## Lab Environment

### Physical Cisco Equipment
- Cisco 1841 Routers
- Cisco Catalyst 3550 Series Switches

### Virtual Lab Platforms
- GNS3
- Cisco Packet Tracer

## Objective

To build practical networking skills through hands-on configuration, verification, troubleshooting, and implementation of Cisco-based networks.
