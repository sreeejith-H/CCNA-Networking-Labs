Switching

This section contains my hands-on CCNA switching labs using Cisco IOS, physical Cisco hardware, GNS3, and Cisco Packet Tracer.

## Topics Covered

- VLANs
- Access Ports
- Trunking
- Inter-VLAN Routing
- VTP
- STP
- Root Bridge
- PortFast
- BPDU Guard
- EtherChannel
- MAC Address Table
- Layer 2 Troubleshooting

### Physical Hardware
- Cisco Catalyst 3550 Series Switches
- Cisco 1841 Router

### Virtual Labs
- GNS3
- Cisco Packet Tracer

## Skills Demonstrated

- Access and trunk port configuration
- Inter-VLAN communication
- STP configuration and verification
- VTP configuration
- EtherChannel configuration
- MAC address table analysis
- Layer 2 troubleshooting
